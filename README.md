# Александр Вторушин

AI-инженер. Делаю LLM-решения для бизнеса и довожу их до прода: агенты и чат-боты, разбор документов и звонков, интеграции с CRM. Веду проект целиком — от разговора с заказчиком до выкатки и поддержки.

За три года около тридцати систем для двадцати заказчиков. Преподаю AI в Передовой школе инженерного дизайна Московского Политеха.

## Чем занимаюсь

**Агенты в проде.** Function calling, structured output, состояние в Postgres, очередь заданий с повторными попытками и идемпотентностью. При низкой уверенности агент передаёт задачу человеку.

**Качество проверяю замером.** Эталонные наборы из реальных входов с ручной разметкой, пороги приёмки зафиксированы до релиза, регресс на каждое изменение промпта или модели. Модель выбираю замером качества, задержки и стоимости вызова.

**Эксплуатация на мне.** Деплой одной командой с автопроверками и откатом по хешу, healthz сервиса и фоновых процессов, алерты, резервные копии с контролем свежести, журнал вызовов модели со стоимостью.

**Claude Code — основной инструмент разработки.** Несколько параллельных сессий по изолированным зонам проекта, правила в `CLAUDE.md`, передача состояния между сессиями файлами в репозитории. Весь сгенерированный код просматриваю построчно.

Коммерческий код закрыт NDA, поэтому здесь лежит то, что можно показать целиком.

**[sales-analysis-agent](https://github.com/Tarcuss0/sales-analysis-agent)** — анализ работы отдела продаж по запросу руководителя: архитектура решения, интеграция с amoCRM и проверки к ней. Видно, как я проектирую агентные системы, где провожу границу между работой модели и обычным кодом, и как тестирую интеграции с внешним API.

**[karaoke-highlighter](https://github.com/Tarcuss0/karaoke-highlighter)** — пет-проект: из скриншота с текстом песни и аудио собирается видео, где слова подсвечиваются в такт. OCR, выравнивание текста по звуку через WhisperX, сшивка двух несовпадающих списков слов, рендер на OpenCV. Самое интересное там — отдельный шаг, который чинит тайминги на проигрышах, и проверка, где подсветка разъехалась.

**[mkd-series-dataset](https://github.com/Tarcuss0/mkd-series-dataset)** — пет-проект про данные: сбор реестров домов из открытых источников, скрейпинг каталога типовых серий, сопоставление свободного текста со справочником и геокодирование миллиона адресов. Там же разбор решения собрать свой геокодер вместо покупного и почему это вышло в тридцать минут вместо трёх месяцев.

## Из того, что сделано под NDA

**Ассистент записи клиентов** — Telegram-агент поверх внешней CRM для сети барбершопов. Третий год в проде, 14 000 прогонов сценария. Запись идёт круглосуточно без администратора.

**Разбор звонков и планёрок** — событие из CRM, запись встречи, распознавание речи, разбор через LLM. Планёрка превращается в задачи с исполнителями и сроками, звонок продаж — в оценку по скрипту из 10 этапов с цитатами. Раньше 20–30 встреч в неделю разбирали руками.

**Обработка B2B-заявок** — позиции извлекаются из писем клиентов и вложений, сводятся с прайсами поставщиков, уходят в счёт. Срок подготовки предложения сократился с недели до двух-трёх дней.

**Чертежи по ГОСТ из планировки квартиры** — распознавание стен, проёмов и размеров связкой OpenCV и vision-модели, расчёт площадей по полигону комнаты, выгрузка в DXF. Комплект, который делался от месяца, собирается за минуты.

Есть портфолио со скриншотами рабочих интерфейсов и архитектуры — пришлю по запросу.
